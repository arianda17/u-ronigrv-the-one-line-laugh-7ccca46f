## The winning line

> "I bought a $14 salad and the app asked if I wanted to round up for charity — yes, please round it down to free."

## Run

```sh
python3 main.py
```

The program asserts the line is a single sentence of 1–200 characters, creates `/output` if needed, writes `/output/entry.txt` (UTF-8) and prints the line.
